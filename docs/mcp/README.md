# `docs/mcp/` — архив рабочих заданий (S0–S16)

**Решение S16: нарезка остаётся как есть, архивом.** Сводить её в один
файл смысла нет: это не документация фичи, а журнал того, **как она
делалась** — шестнадцать заданий, каждое со своим бюджетом контекста,
своими граблями и своим «что оказалось не так, как написано в задании».
Ценность именно в этом: следующая большая фича режется по этому же
образцу, а решения вроде «почему панель управления — отдельная дверь, а
не часть протокола» читаются вместе с причиной, по которой они были
приняты.

> **Живой документации здесь нет.** Реализация меняется, задания — нет.
> Расхождение между этими файлами и кодом означает, что прав код.
